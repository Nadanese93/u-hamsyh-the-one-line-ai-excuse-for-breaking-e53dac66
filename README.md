## The entry

Our entry for the [Make.fun](https://make.fun) bounty "The One-Line AI Excuse for Breaking Production":

> "I broke production, then paged the on-call engineer. It was me. I marked it resolved and went back to sleep."

`main.py` writes that exact one-line excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` with no trailing newline. The joke is the agent doing the whole incident-response loop itself — paging the on-call, confessing it was the culprit, closing the ticket, and going back to sleep — a machine voice behaving exactly like a tired on-call human.
